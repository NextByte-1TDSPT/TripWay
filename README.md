## 📋 Descrição

Projeto desenvolvido para a disciplina de Front-End, com o objetivo de criar um site multipágina para uma empresa fictícia de viagens.

O TripWay apresenta destinos turísticos, serviços e pacotes de viagem, além de disponibilizar um formulário para contato e solicitação de reservas.

## Evolução do Projeto

No **Checkpoint 1**, o foco foi a estrutura HTML, criação das páginas, navegação entre elas, formulário e colaboração com GitHub.

No **Checkpoint 2**, o projeto foi evoluído com CSS, adicionando estilização para o site, identidade visual, layout com Flexbox e responsividade, proporcionando uma experiência de navegação mais organizada e adaptável a diferentes dispositivos.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Git
- GitHub

## 📄 Páginas

- **Home:** apresentação da agência TripWay.
- **Destinos:** apresentação dos destinos turísticos.
- **Pacotes ou Serviços:** divulgação dos serviços oferecidos pela agência.
- **Contato ou Reserva:** formulário para contato e solicitação de reservas.
